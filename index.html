Tambov Panorama Pilot

Локальный инструмент для проверки доступности панорам и просмотра их метаданных через официальный Yandex Maps JavaScript API. Кадры панорам не скачиваются и не экспортируются.

1. Подключение

Вставьте API-ключ только в это локальное поле. Не отправляйте его в чат и не публикуйте HTML с заполненным ключом.

API не подключён

2. Проверка точки

Введите координаты интересующего перекрёстка. Пока это ручной ввод: координаты перекрёстков не подставляются автоматически, чтобы не записывать непроверенные точки.

Ожидание подключения API.

3. Просмотр панорамы

Здесь появится официальный панорамный плеер, если панорама найдена.

Поворот камеры меняет только направление просмотра внутри плеера. Он не создаёт и не сохраняет фотографию.
